# UdayFin

My personal money app: track spending (High ON / Low ON), accounts, debts with a debt-free plan, savings, investments and a Rs 30 lakh goal. Includes Babe, a voice money assistant.

**Open the app:** https://uday-fin.github.io/udayfin/

It works offline after the first visit. All money data stays on the phone (browser storage); nothing personal is stored in this repository.

Install on Android: open the link in Chrome → ⋮ → Install app.
